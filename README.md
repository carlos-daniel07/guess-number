# 🔢 Number Guessing Engine - JS Fundamentals

Ejercicio interactivo enfocado en los fundamentos de Vanilla JavaScript, la lógica condicional y la manipulación dinámica del Document Object Model (DOM).

🔗 **[Ver Proyecto en Vivo](https://number-riddle.netlify.app/)**

## 🚀 Arquitectura y Lógica

* **Algoritmia Básica:** Generación de valores pseudoaleatorios utilizando `Math.random()` para establecer estados iniciales.
* **Validación de Datos (Sanitization):** Implementación de bloqueos lógicos para evitar entradas inválidas, verificando rangos numéricos estrictos (1 al 100) y manejando excepciones de tipo `NaN`[cite: 8].
* **Manipulación del DOM:** Actualización de la interfaz gráfica en tiempo real mediante la inyección de texto (`textContent`) y la modificación dinámica de estilos en línea en respuesta a las acciones del usuario[cite: 8].
* **Event Handling:** Integración directa de funciones manejadoras de eventos en la estructura HTML[cite: 10].

## 🛠️ Tecnologías Utilizadas

* **JavaScript (Vanilla)**
* **HTML5 & CSS3**

## 🧠 Objetivo del Proyecto
El propósito de este desarrollo es consolidar los conceptos fundamentales de la programación en cliente: captura de valores de inputs, control de flujo (`if/else`), actualización de contadores de estado y manipulación directa de nodos del DOM sin intermediarios.
